# نظام ملف الإنجاز للمشتركات — PWA

ضع ملف الأيقونة الأصلي `200.png` (بمقاس 512×512 بكسل) في جذر المجلد قبل الرفع. تستخدمه الصفحة وملف `manifest.webmanifest` تلقائياً كأيقونة للشاشة الرئيسية والتطبيق المثبت.

توجّه هذه النسخة إلى الرابط: `https://teacherhub-e9sten9g.manus.space/female`، وهي مستقلة في معرّف التطبيق وذاكرة التخزين عن النسخة العامة.

ملفات الـPWA المطلوبة محفوظة في الجذر: `index.html` و`manifest.webmanifest` و`sw.js` و`manus-routes.json`.
